Task 10. Mouse and focus events

Events: mouseenter / mouseleave and focus / blur.

Interactive card

Hover over the card or press Tab to focus it.

Which event triggers each change?

  • mouseenter – the pointer enters the card: adds the highlight class and changes the instruction text.
  • mouseleave – the pointer leaves the card: removes highlight and restores the original text.
  • focus – the card receives keyboard focus (Tab): the same highlight and text as on hover.
  • blur – the card loses focus: the highlight is removed and the original text is restored.
